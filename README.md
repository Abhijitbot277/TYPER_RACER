# TYPER RACER

An original offline typing-racing game built with React + TypeScript + Vite.

## Features
- Real-time typing race against four local AI opponents
- WPM, accuracy, elapsed-time and progress tracking
- Coins, XP, levels and race rewards
- Offline garage with five unlockable cars
- Car selection and upgrade system
- Local progression using browser localStorage
- No account, backend, Firebase or network dependency for gameplay
- Responsive desktop/mobile UI

## Run locally
\`\`\`bash
npm install
npm run dev
\`\`\`

Production build:
\`\`\`bash
npm run build
\`\`\`

The game is designed to keep working offline after the app assets have been installed/cached. All progression is stored on the device.
